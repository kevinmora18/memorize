# 📝 Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-05-26

### 🎉 Lanzamiento Inicial

#### ✨ Agregado

**Modos de Juego:**
- Modo Clásico con 10 niveles progresivos
- Modo Infinito sin límite de niveles
- Modo Desafío con cartas especiales
- Boss Fight con 5 jefes temáticos
- Multijugador en tiempo real (hasta 4 jugadores)
- IA Friends para práctica

**Sistema de Personalización:**
- 8 packs de cartas temáticos
- 6 skins para cartas
- 6 marcos decorativos
- 6 tableros de juego
- Tienda integrada con monedas y gemas

**Sistema de Progresión:**
- Sistema de niveles y experiencia (XP)
- Estadísticas detalladas de jugador
- Tabla de clasificación global
- Historial de partidas
- Logros y recompensas

**Panel de Administración:**
- Gestión completa de usuarios
- Sistema de baneos (temporal/permanente)
- Anuncios globales
- Analíticas en tiempo real
- Gestión de economía
- Historial de partidas
- Promociones y eventos

**Backend:**
- API RESTful con Express
- Base de datos PostgreSQL con Prisma ORM
- WebSockets para multijugador
- Sistema de autenticación
- Endpoints de administración

**Frontend:**
- Interfaz moderna con React 18
- Animaciones con Framer Motion
- Diseño responsivo con Tailwind CSS
- Comunicación en tiempo real con Socket.io

#### 🔧 Técnico

- TypeScript en frontend y backend
- Arquitectura modular y escalable
- Documentación completa
- Variables de entorno configurables
- Sistema de migraciones de base de datos

#### 📚 Documentación

- README completo con instrucciones
- Guía de contribución
- Documentación de API
- Guía de despliegue
- Changelog
